# 五笔打字练习 · 86 版

单文件的五笔打字练习工具：屏幕给一个字或一个二字词，用你习惯的输入法打出来，上屏即判定。不安装、不登录、不联网。

**在线版：** <https://snihqi.github.io/wubi86-typing/>
姊妹项目：[五笔字根练习](https://snihqi.github.io/wubi86-roots/)，共用同一套版式、段位表和计分规则。

## 用法

在输入框里打字。答错不换题，打到对为止；第一次碰到和刚打错的字会显示五笔编码。判定只看上屏的字，用什么输入法都一样。

- 左上角下拉切换分组：单字分前 500 / 中 500 / 后 500，词组分前 600 / 中 600 / 后 500，最后一档可自建字表，各组进度互不干扰
- 词组组一次打两个字，两个字都上屏才判定；打对第一个字会留在框里等第二个
- 点「查看拆分与编码」或按 `Tab` 展开拆解，虚线框里是末笔字型识别码；词组还会给出词组码（首字前两码 + 次字前两码）
- 答对得 **1 × 连击档位** 分；答错不得分、不扣分，连击归零，熟练度退两档
- 分数只影响段位，出题顺序按熟练度算；段位共 50 级（Lv1 白身 → Lv50 首辅），与字根版同一张表
- 每日任务四档共用今日计数，`06:00` 清零；达标点「领取」，按当前总分百分比加分

右上角的太阳 / 月亮图标切换浅色、深色，旁边可以跳回[五笔字根练习](https://snihqi.github.io/wubi86-roots/)；主题偏好在两个工具间共用。

进度自动存在浏览器本地，每个分组各存一份；换设备用「导出进度」/「导入进度」，导出的文件名带工具名（`五笔打字练习_进度_日期.json`），不会和字根版混。改了文件名或网址，旧进度就读不到。
本工具 2026-11 之前叫「五笔单字练习」，那时导出的 `五笔单字练习_进度_*.json` 现在仍能正常导入。
按桌面宽度设计，手机能打开，练起来还是桌面舒服。

## 数据来源与许可

五笔编码、字根拆解、拼音笔画取自 [sdcb/search-wubi](https://github.com/sdcb/search-wubi) →
[sdcb/wubi86-viewer](https://github.com/sdcb/wubi86-viewer) 的导出文件。前者未附 LICENSE，本项目只取其中可独立核验的
编码事实，不复制其代码与文档；拆解字段上游记为 86wb.ysepan.com，未注明许可。字根字形与字根版同源。
未采用微软五笔词库和 Make Me a Hanzi 笔画数据。

五笔 86 方案（王永民，1983）属公有领域。二字词表取自公开的人民日报常用词表（1,700 个字频靠前的词），
词组码按 86 版规则由两字的字全码现拼，不另存对照表。本项目许可见 [LICENSE](LICENSE)（AGPL-3.0）。
源码即 `index.html` 本身，无构建、无压缩。
