# 五笔打字练习 · 86 版

五笔 86 版打字练习，单文件网页，打开即用。给出一个单字或词组，用五笔打出来，上屏判定；答错不换题，首次遇到和刚打错的字会提示编码。

**在线版：** <https://snihqi.github.io/wubi86-typing/> ｜ 也可下载 `index.html` 本地双击打开。
姊妹项目：[五笔字根练习](https://snihqi.github.io/wubi86-roots/)。

## 说明

- 单字 3,000 个按字频分六组；词组 3,000 个，另有 241 个日常常用词
- 按 `Tab` 展开拆解，笔画按码序上色，不取码的笔画画灰
- 答对按连击倍率计分，段位 155 级，满级后分数继续累积
- 每日四档任务，`06:00` 清零
- 界面固定深色；进度存浏览器本地，可导出导入

编码与字根拆解取自 [sdcb/search-wubi](https://github.com/sdcb/search-wubi) 与 [sdcb/wubi86-viewer](https://github.com/sdcb/wubi86-viewer)，笔画字形取自 [Make Me a Hanzi](https://github.com/skishore/makemeahanzi)（Arphic Public License）。五笔 86 方案（王永民，1983）属公有领域。本项目许可见 [LICENSE](LICENSE)（AGPL-3.0）。
